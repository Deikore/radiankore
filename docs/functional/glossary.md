# Glosario funcional

| Término | Definición en esta documentación |
| --- | --- |
| Aceptación | Manifestación o situación de aceptación de la factura, conforme a la modalidad y requisitos aplicables |
| Antecedente | Hecho, documento o evento que debe examinarse antes de realizar otro acto |
| Aval | Garantía sobre una obligación del título, con alcance y personas determinados |
| Cesión | Transferencia de derechos conforme al negocio y régimen que corresponda |
| Circulación | Actuaciones mediante las que se transfieren o ejercen derechos del título, sujetas a sus condiciones |
| CUDE | Código único que identifica el documento de un evento |
| CUFE | Código único que identifica una factura electrónica |
| Endoso | Acto sobre el título cuya finalidad puede ser propiedad, garantía, procuración u otra prevista |
| Evento | Constancia de un hecho o declaración relacionados con una factura o con otro evento |
| Facultad | Autorización suficiente para realizar un acto determinado en la calidad correspondiente |
| Factura electrónica de venta | Documento que respalda una venta de bienes o prestación de servicios |
| Legítimo tenedor | Persona legitimada para ejercer los derechos del título según sus antecedentes |
| Mandato | Encargo aceptado para actuar por cuenta de otro dentro de facultades y condiciones determinadas |
| Nota crédito o débito | Documento relacionado con la factura que debe distinguirse de los eventos de recepción, aceptación o circulación |
| Protesto | Actuación que deja constancia de la causa aplicable, con sus requisitos y soporte |
| RADIAN | Registro administrado por DIAN para consulta y trazabilidad de facturas como título valor y sus eventos |
| Saldo | Valor pendiente después de considerar los pagos y condiciones que correspondan |
| Soporte | Documento o evidencia que sustenta el acto declarado |
| Título valor | Documento al que corresponden los requisitos y derechos previstos por el régimen comercial aplicable |
| Validación | Resultado del examen que realiza DIAN sobre el documento; se distingue de la ocurrencia del hecho comercial |
| Vencimiento | Fecha en que debe atenderse la obligación según sus condiciones |

Las definiciones facilitan la lectura. Para condiciones y efectos particulares,
consulte el evento correspondiente y sus [fuentes](sources.md).
