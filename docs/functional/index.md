# Documentación funcional

Esta parte explica el proceso de negocio: qué representa cada documento, quién
interviene y qué condiciones deben cumplirse para registrar un evento. Puede
leerse sin conocimientos de programación.

La exposición se basa en Factura Electrónica 1.9 y RADIAN 1.1. Las fuentes de cada
capítulo permiten identificar su alcance y consultar las reglas originales.
Las situaciones comerciales utilizadas son ficticias.

## Orden de lectura

Primero distinga la factura, su condición de título valor y sus eventos. Después
identifique los actores. Consulte las páginas de eventos para establecer las
condiciones de un acto concreto y los procesos para comprender su relación con
otros actos. No existe una secuencia obligatoria que incluya todos los eventos.
